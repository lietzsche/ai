1. 스킬 시스템 구조

스킬은 에이전트 능력을 확장하는 오픈 표준입니다. SKILL.md가 들어 있는 폴더 하나가 스킬 하나입니다.

폴더 구성 공식 확인

my-skill/
├── SKILL.md    # 필수: 지침과 메타데이터
├── scripts/    # 선택: 실행 스크립트
├── examples/   # 선택: 참고 구현
└── resources/  # 선택: 템플릿·스키마·데이터
출처: Agent skills 문서 ↗

Frontmatter 공식 확인

  • name (선택): 소문자·하이픈 식별자. 없으면 폴더 이름
  • description (필수): 무엇을 하고 언제 쓰는지. 에이전트가 이 값으로 사용 여부를 판단

설명은 3인칭으로, 인식에 도움이 되는 키워드를 넣도록 권장합니다.

출처: Agent skills 문서 ↗

점진적 공개 방식 공식 확인

  • 발견: 매 턴 스킬 이름·설명 목록만 봄
  • 활성화: 관련 있어 보이면 SKILL.md 전체를 읽음
  • 실행: 지침에 따라 작업

명시하지 않아도 맥락으로 판단하며, 이름을 언급하면 확실히 사용합니다.

출처: Agent skills 문서 ↗

작성 모범 사례 공식 확인

  • 스킬 하나는 한 가지 일에 집중
  • 구체적인 description 작성
  • 스크립트는 블랙박스로: 먼저 --help 실행 권장
  • 복잡한 스킬엔 의사결정 트리 추가
출처: Agent skills 문서 ↗

2. CLI 스킬 경로와 호출

CLI는 아래 위치에서 스킬을 읽고, 각 스킬을 슬래시 명령으로 자동 변환합니다.

위치범위
<workspace>/.agents/skills/<skill>/워크스페이스 전용 (상위 폴더의 .agents/skills/도 저장소 루트까지 탐색). 구버전 .agent/skills도 호환
~/.gemini/config/skills/<skill>/전역 (Antigravity App과 공유)
~/.gemini/config/plugins/<plugin>/skills/플러그인이 제공하는 스킬
~/.gemini/antigravity-cli/skills/, ~/.gemini/skills/CLI 전용 (App은 읽지 않음)

슬래시 명령 자동 변환 공식 확인

스킬 deploy-staging을 만들면 TUI에서 /deploy-staging을 쓸 수 있습니다. 실행 중 스킬을 추가했다면 /skills reload를 실행하거나 새 대화를 시작합니다.

출처: Agent skills 문서 (CLI 탭) ↗

플러그인으로 관리 공식 확인

agy plugin list [--json]
agy plugin install <plugin-name>
agy plugin install https://github.com/<owner>/<repo>
agy plugin install ./my-skills-plugin

기본 마켓플레이스는 @antigravity-plugins-official입니다.

3. 내장 슬래시 명령

프롬프트에서 /를 입력하면 나타나는 기본 명령입니다. 명령 목록 페이지는 자동 조회가 막혀(403) 일부는 검색 요약에 의존했습니다.

/grill-me 공식 확인

바로 실행하지 않고 한 번에 한 질문씩 사용자를 인터뷰해, 추천 답과 함께 요구사항을 정리합니다. 모호한 작업에 적합합니다.

출처: /grill-me 문서 ↗

/goal 미확인

목표가 완전히 달성될 때까지 중간 확인 없이 자율 실행합니다. 대규모 리팩터링·마이그레이션용. /grill-me로 범위를 정한 뒤 넘기는 패턴이 소개됩니다.

출처: 웹 검색 요약 (공식 문서 직접 미확인) ↗

/schedule 미확인

지시를 일회성 타이머나 반복 cron으로 예약해 현재 대화에서 에이전트를 깨웁니다.

출처: 웹 검색 요약 ↗

/browser 미확인

웹 조사와 UI 점검을 위한 샌드박스 브라우저 서브에이전트를 실행합니다.

출처: 웹 검색 요약 ↗

/teamwork-preview 미확인

여러 에이전트 팀이 대형 프로젝트를 자율 협업으로 처리합니다. 유료 플랜이 필요하다는 언급이 있습니다.

출처: 웹 검색 요약 ↗

/skills 공식 확인

스킬 관련 명령. 공식 문서에서는 /skills reload로 새 스킬을 반영하는 용도가 확인됩니다.

5. 이 저장소(lietzsche/ai)의 연결

공통 원본은 skills/에 두고, 도구별로 얇은 진입점을 둡니다.

경로역할
skills/<name>/SKILL.md공통 원본 (실제 지침)
.agents/skills/<name>/SKILL.mdCodex 진입점이면서 Antigravity의 기본 워크스페이스 경로 → /grill-me, /make-plan으로 노출
.claude/skills/<name>/SKILL.mdClaude Code 진입점

grill-me

아이디어를 한 번에 한 질문씩 인터뷰해 요구사항으로 정리합니다. Antigravity 내장 /grill-me와 이름이 같으므로 어느 쪽이 호출되는지는 실제 클라이언트에서 확인이 필요합니다.

make-plan

확정된 요구사항을 단계·산출물·검증·위험이 담긴 실행 계획으로 만듭니다. grill-me 요약에서 이어지는 체인을 지원합니다.
