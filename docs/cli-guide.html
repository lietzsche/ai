Linux · Ubuntu · Bash

1. 파일을 기본 앱으로 열기 (start 대응)

리눅스 데스크톱에서는 xdg-open이 윈도우의 start 역할을 합니다. 파일 형식에 연결된 기본 앱으로 엽니다.

윈도우리눅스동작
start file.htmlxdg-open file.html기본 브라우저로 HTML 파일 열기
start https://example.comxdg-open https://example.com기본 브라우저로 URL 열기
start .xdg-open .현재 폴더를 파일 관리자로 열기
start report.pdfxdg-open report.pdfPDF 뷰어 등 연결된 앱으로 열기
start chrome file.htmlgoogle-chrome file.html, firefox file.html브라우저를 직접 지정해 열기(해당 브라우저가 설치된 경우)

xdg-open 표준

파일이나 URL을 사용자가 지정한 기본 앱으로 엽니다. GNOME·KDE 등 데스크톱 환경을 가리지 않는 freedesktop 표준 도구입니다.

xdg-open file.html
xdg-open ~/Downloads
출처: xdg-open ↗

open Ubuntu

Ubuntu에서는 open이 xdg-open으로 연결되어 있어 macOS처럼 open file.html도 됩니다. 이 PC에서 readlink -f $(command -v open) 결과가 /usr/bin/xdg-open인 것을 확인했습니다. 다른 배포판에서는 다를 수 있습니다.

gio open GNOME

GNOME의 GIO 도구로 기본 앱에서 엽니다. 파일 형식에 등록된 기본 앱을 사용한다는 점은 xdg-open과 같습니다.

gio open file.html

터미널 기본 요령

  • Tab: 명령·파일 이름 자동완성
  • ↑/↓: 이전 명령 불러오기, Ctrl+R: 기록 검색
  • Ctrl+C: 실행 중인 명령 중단
  • ~는 홈 폴더, .은 현재, ..은 상위 폴더
  • ./script.sh: 현재 폴더의 실행 파일 실행

도움말 보기

윈도우의 help, 명령 /?에 해당합니다. man 명령은 전체 매뉴얼(q로 종료), 명령 --help는 짧은 사용법, bash 내장 명령은 help cd처럼 봅니다.

man ls
ls --help
help cd

2. 핵심 명령

처음 리눅스 터미널을 쓸 때 가장 자주 쓰는 명령입니다. 태그는 윈도우 대응 명령입니다.

ls dir

폴더 내용 보기. ls -l 자세히, ls -a 숨김 파일 포함, ls -lh 크기를 읽기 쉽게.

cd cd

폴더 이동. cd .. 상위, cd ~ 또는 cd 홈, cd - 직전 폴더.

cp · mv · rm copy · move · del

복사·이동(이름 변경)·삭제. 폴더는 cp -r, rm -r. rm은 휴지통을 거치지 않음

mkdir mkdir

폴더 만들기. mkdir -p a/b/c로 중간 폴더까지 한 번에.

cat · less type · more

파일 내용 보기. 긴 파일은 less로 페이지 단위로 보고 q로 나옵니다.

grep findstr

텍스트 검색. grep -rn "TODO" .로 하위 폴더까지 줄 번호와 함께 찾기.

find dir /s

파일 찾기. find . -name "*.html"로 현재 폴더 아래 HTML 파일 찾기.

sudo 관리자 권한 실행

다른 사용자(기본 root) 권한으로 명령 실행. 패키지 설치·시스템 설정 변경에 필요.

apt winget

Ubuntu 패키지 관리. sudo apt update 후 sudo apt install tree.

ps · kill tasklist · taskkill

프로세스 목록과 종료. ps aux로 전체를 보고 kill PID로 종료.

ip · ss ipconfig · netstat

ip addr로 IP 주소, ss -tlnp로 열린 TCP 포트와 프로세스 확인.

df · du · free 작업 관리자

디스크 여유 공간(df -h), 폴더 크기(du -sh 폴더), 메모리(free -h).

3. 전체 명령

분류별로 자주 쓰는 명령입니다. “윈도우 대응”은 cmd 기준이며 PowerShell 명령은 PS로 표시했고, 동작이 정확히 같지는 않습니다.

명령을 클릭하거나 Tab으로 이동해 Enter를 누르면 자세한 설명과 사용 예, 공식 문서 링크가 펼쳐집니다. 검색어와 펼친 항목은 주소에 남아 그대로 공유할 수 있습니다.

Windows PowerShell

1. 시작하기

PowerShell은 텍스트가 아니라 객체를 파이프라인으로 넘깁니다. 이 차이만 알면 대부분의 명령을 조합할 수 있습니다.

실행과 버전

  • Win+X → 터미널, 또는 Win+R → powershell
  • Windows PowerShell 5.1(powershell.exe)은 Windows 기본 탑재, PowerShell 7(pwsh.exe)은 별도 설치
  • 버전 확인: $PSVersionTable
  • 관리자 권한: 터미널을 오른쪽 클릭 → 관리자 권한으로 실행
출처: What is PowerShell? ↗

명령 찾기와 도움말

  • 이름은 동사-명사 형식: Get-Process, Stop-Service
  • Get-Command *service* 명령 찾기
  • Get-Help Get-Process -Examples 예제 보기 (처음엔 Update-Help)
  • Get-Process | Get-Member 객체 속성·메서드 확인
  • Tab 자동완성, Ctrl+Space 후보 목록
출처: The Help system ↗

파이프라인과 연산자

  • | 객체를 다음 명령으로 전달, $_(또는 $PSItem)가 현재 객체
  • 비교: -eq -ne -gt -lt -like -match
  • 논리: -and -or -not
  • >·>> 리디렉션, 2>&1 오류 합치기
  • 변수 $name = 값, 환경 변수 $env:PATH

cmd·Linux 별칭 5.1 기준

dir, ls, cd, cp, rm, cat, ps, kill 같은 익숙한 이름이 cmdlet의 별칭으로 등록돼 있습니다. 다만 옵션은 원래 명령과 다릅니다(ls -la는 동작하지 않음). 스크립트에서는 전체 이름을 쓰는 것이 권장됩니다.

PowerShell 7에서는 curl, wget 등 일부 별칭이 제거되었으니 Get-Alias로 확인하세요.

출처: about_Aliases ↗

2. 핵심 명령

가장 자주 쓰는 cmdlet입니다. 자세한 매개변수는 3번 표에서 행을 클릭해 확인하세요.

Get-ChildItem 파일

폴더 목록(dir, ls). -Recurse 하위 포함, -Filter 이름 필터, -Force 숨김 포함.

Copy-Item / Remove-Item 파일

복사·삭제. 폴더째 처리할 땐 -Recurse, 실행 전 확인은 -WhatIf.

Get-Content 텍스트

파일 읽기(cat). -Tail 20 -Wait로 로그 실시간 보기.

Select-String 텍스트

문자열·정규식 검색(grep과 비슷). -Pattern, -Path.

Where-Object 파이프라인

조건으로 객체 거르기. ... | Where-Object CPU -gt 100.

Select-Object / Sort-Object 파이프라인

원하는 속성만 고르고 정렬. -First 5, -Descending.

Get-Process / Stop-Process 시스템

프로세스 확인과 종료. Stop-Process -Name notepad -Force.

Get-Service 시스템

서비스 상태 확인. 시작·중지는 Start-Service, Stop-Service.

Test-NetConnection 네트워크Windows 전용

연결·포트 확인. Test-NetConnection example.com -Port 443.

Invoke-RestMethod 네트워크

HTTP 요청 후 JSON을 객체로 변환. API 호출에 적합.
