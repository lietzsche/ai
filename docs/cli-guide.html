목적별 Linux ↔ PowerShell 실무 해법

자주 겪는 6가지 문제를 두 셸의 표준 명령으로 나란히 풀었습니다. 삭제·종료·동기화 작업은 아래 안전 흐름을 먼저 거치세요.

포트 점유 프로세스 찾고 종료 네트워크 · 프로세스

종료 전 PID와 실행 파일 이름을 먼저 대조하고, 정상 종료가 응답하지 않을 때만 강제 종료하세요.

Linux · Bash 
sudo ss -tlnp | grep :8080
kill 12345          # 응답 없을 때만 kill -9 12345
Windows PowerShell 
Get-NetTCPConnection -LocalPort 8080 |
  Select-Object LocalPort, OwningProcess
Stop-Process -Id 12345 -WhatIf

실시간 로그 추적과 오류 줄 검색 로그 · 텍스트

실시간 추적은 Ctrl+C로 중단합니다. 대용량 과거 로그는 페이지 뷰어나 문자열 검색으로 먼저 좁히세요.

Linux · Bash 
tail -f app.log
grep -rn "ERROR" ./logs
Windows PowerShell 
Get-Content .\app.log -Tail 50 -Wait
Get-ChildItem -Recurse .\logs\*.log |
  Select-String -Pattern 'ERROR'

디스크 여유 확인과 대용량 항목 찾기 디스크 · 파일

파티션 전체 여유 공간을 먼저 본 뒤, 용량이 큰 하위 폴더·파일 순서로 좁혀 내려갑니다.

Linux · Bash 
df -h
du -sh * | sort -h
Windows PowerShell 
Get-Volume
Get-ChildItem -Recurse -File |
  Sort-Object Length -Descending |
  Select-Object -First 10 Name, Length

사전 검증 후 폴더 백업·압축 배포 동기화 · 압축

rsync는 원본 경로 끝 / 유무로 구조가 달라지므로 -n으로 먼저 확인하세요.

Linux · Bash 
rsync -avn src/ backup/   # 확인 후 -av 실행
tar -czf release.tar.gz dist/
Windows PowerShell 
Copy-Item .\src D:\backup\src -Recurse -WhatIf
Compress-Archive -Path .\dist\* -DestinationPath release.zip

스크립트 실행 허용과 백그라운드 유지 권한 · 세션

외부에서 내려받은 스크립트는 실행 권한·정책을 열기 전에 내용을 먼저 검토하세요.

Linux · Bash 
chmod +x ./server.sh
nohup ./server.sh &
jobs -l
Windows PowerShell 
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
$job = Start-Job { .\worker.ps1 }
Receive-Job $job -Wait

HTTP API 응답 확인과 파일 다운로드 네트워크 · API

PowerShell 5.1의 curl은 별칭이므로 원래 curl 플래그를 쓰려면 curl.exe를 입력합니다.

Linux · Bash 
curl -I https://example.com
curl -L -o file.zip https://example.com/file.zip
Windows PowerShell 
Invoke-RestMethod https://api.github.com/zen
Invoke-WebRequest https://example.com/file.zip -OutFile file.zip

1. 시작하기와 기본 앱으로 파일 열기 (start 대응)

리눅스 데스크톱에서는 xdg-open이 윈도우 start 역할을 맡아 파일 형식에 연결된 기본 앱을 실행합니다.

윈도우 (cmd)리눅스 (Bash)동작

start .xdg-open .현재 폴더를 파일 관리자로 열기

xdg-open 표준

파일이나 URL을 사용자가 지정한 기본 앱으로 엽니다. GNOME·KDE 등 데스크톱 환경을 가리지 않는 freedesktop 표준 도구입니다.

xdg-open file.html
xdg-open ~/Downloads
출처: xdg-open 매뉴얼 ↗

open Ubuntu

Ubuntu에서는 open이 xdg-open으로 연결되어 있어 macOS처럼 open file.html도 동작합니다. 이 PC에서 readlink -f $(command -v open) 결과가 /usr/bin/xdg-open인 것을 확인했습니다. 다른 배포판에서는 다른 명령일 수 있습니다.

gio open GNOME

GNOME의 GIO 명령줄 도구로 기본 앱을 실행합니다. 파일 형식에 등록된 기본 앱을 찾는다는 점은 xdg-open과 같습니다.

gio open file.html

터미널 기본 조작

  • Tab: 명령·경로 이름 자동완성
  • ↑/↓: 이전 명령 탐색, Ctrl+R: 명령 기록 역검색
  • Ctrl+C: 실행 중인 작업에 중단 신호 전달
  • ~ 홈 폴더, . 현재 폴더, .. 상위 폴더
  • ./script.sh: 실행 권한이 있는 현재 폴더 스크립트 실행
출처: GNU Bash 매뉴얼 ↗

내장 도움말 확인

윈도우의 help, 명령 /?에 대응합니다. 전체 매뉴얼은 man 명령(q로 종료), 요약 옵션은 명령 --help, bash 내장 명령은 help cd로 확인합니다.

man ls
ls --help
help cd

2. 입문 핵심 명령 12선

리눅스 터미널에서 반복해 쓰는 기본 명령입니다. 오른쪽 태그는 대응하는 윈도우 명령입니다.

ls dir

폴더 내용 나열. ls -l 상세 권한·시각, ls -a 숨김 파일 포함, ls -lh K·M·G 단위 크기 표시.

cd cd

작업 폴더 이동. cd .. 상위 폴더, cd ~ 또는 cd 홈 폴더, cd - 직전 폴더 복귀.

cp · mv · rm copy · move · del

주의: rm은 휴지통 미경유 복사·이동(이름 변경)·즉시 삭제. 폴더 재귀 처리는 cp -r, rm -r.

mkdir mkdir

폴더 생성. 중간 경로까지 한 번에 만들려면 mkdir -p a/b/c를 씁니다.

cat · less type · more

파일 내용 출력·열람. 긴 파일은 less로 한 화면씩 넘겨 보고 q로 종료합니다.

grep findstr

패턴 일치 줄 검색. 하위 폴더 전체를 줄 번호와 함께 찾으려면 grep -rn "TODO" .을 실행합니다.

find dir /s

조건별 파일 탐색. 현재 경로 아래 HTML 파일은 find . -name "*.html"로 찾습니다.

sudo 관리자 권한 실행

다른 사용자(기본 root) 권한으로 단일 명령 실행. 패키지 설치·시스템 서비스 변경 전에 붙입니다.

apt winget

Ubuntu·Debian 패키지 관리. sudo apt update로 목록을 갱신한 뒤 sudo apt install tree로 설치합니다.

ps · kill tasklist · taskkill

프로세스 조회와 종료 신호 전달. ps aux로 PID를 확인한 뒤 kill PID를 실행합니다.

ip · ss ipconfig · netstat

네트워크 인터페이스·소켓 확인. ip addr로 IP를, ss -tlnp로 수신 대기 TCP 포트와 프로세스를 봅니다.

df · du · free 작업 관리자

자원 사용량 확인. 파일시스템 여유(df -h), 특정 경로 용량(du -sh 폴더), 메모리·스왑(free -h).

Windows PowerShell

1. 시작하기와 객체 파이프라인

PowerShell은 문자열 대신 형식화된 .NET 객체를 파이프라인으로 넘깁니다. 동사-명사 규칙과 객체 속성 조회만 익히면 출력 텍스트를 다시 자를 필요가 없습니다.

실행과 버전 구분

  • Win+X → 터미널, 또는 Win+R → powershell
  • Windows PowerShell 5.1(powershell.exe)은 Windows 기본 탑재, PowerShell 7(pwsh.exe)은 별도 설치
  • 현재 세션 버전 확인: $PSVersionTable
  • 관리자 권한 필요 시: 터미널 아이콘 우클릭 → 관리자 권한으로 실행
출처: What is PowerShell? ↗

명령 탐색과 도움말

  • 모든 cmdlet은 동사-명사 형식: Get-Process, Stop-Service
  • 명령 검색: Get-Command *service*
  • 실행 예제 확인: Get-Help Get-Process -Examples (최초 1회 Update-Help)
  • 반환 객체의 속성·메서드 확인: Get-Process | Get-Member
  • Tab 자동완성, Ctrl+Space 후보 목록 표시
출처: The Help system ↗

파이프라인과 비교 연산자

  • | 객체를 다음 cmdlet으로 전달, $_(또는 $PSItem)가 현재 객체
  • 비교 연산자: -eq -ne -gt -lt -like -match
  • 논리 연산자: -and -or -not
  • 리디렉션: > 덮어쓰기, >> 이어 쓰기, 2>&1 오류 스트림 병합
  • 변수 선언 $name = 값, 환경 변수 조회 $env:PATH
출처: about_Pipelines ↗

cmd·Linux 별칭 주의점 5.1 기준

dir, ls, cd, cp, rm, cat, ps, kill은 대응 cmdlet의 별칭으로 등록돼 있으나, 매개변수는 PowerShell 규칙을 따릅니다(ls -la는 오류 발생). 재사용할 스크립트에서는 항상 전체 cmdlet 이름을 쓰세요.

PowerShell 7에서는 충돌을 막기 위해 curl, wget 별칭이 제거되었습니다. 현재 세션 기준 연결은 Get-Alias로 확인하세요.

2. 입문 핵심 명령 10선

파일·텍스트·파이프라인·시스템·네트워크에서 가장 먼저 익힐 핵심 cmdlet입니다.

Get-ChildItem 파일

폴더 항목 나열(dir, ls). -Recurse 하위 포함, -Filter 고속 이름 필터, -Force 숨김 포함.

Copy-Item / Remove-Item 파일

-WhatIf 선행 권장 복사·영구 삭제. 하위 폴더 전체는 -Recurse를 붙입니다.

Get-Content 텍스트

파일 내용 읽기(cat). 실시간 로그 추적은 -Tail 20 -Wait를 붙입니다.

Select-String 텍스트

문자열·정규식 패턴 검색(grep 대응). -Path와 -Pattern으로 지정합니다.

Where-Object 파이프라인

속성 조건으로 객체 걸러내기. 예: Get-Process | Where-Object CPU -gt 100.

Select-Object / Sort-Object 파이프라인

필요한 속성만 추리고 정렬. 상위 n개는 -First 5, 내림차순은 -Descending.

Get-Process / Stop-Process 시스템

프로세스 객체 조회와 종료. 강제 종료 전 대상 프로세스 이름·ID를 먼저 확인하세요.

Get-Service 시스템

Windows 서비스 상태 조회. 시작·중지는 관리자 권한에서 Start-Service, Stop-Service를 씁니다.

Test-NetConnection 네트워크Windows 전용

ICMP 응답·TCP 포트·라우팅 경로 통합 진단. 예: Test-NetConnection example.com -Port 443.

Invoke-RestMethod 네트워크

HTTP·REST API 호출 후 JSON·XML 응답을 즉시 PowerShell 객체로 변환합니다.
