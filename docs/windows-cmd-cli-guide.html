Windows 명령어(cmd) 정리

명령 프롬프트(cmd.exe)에서 자주 쓰는 명령어를 Microsoft Learn의 Windows commands 레퍼런스 기준으로 정리했습니다.

1. 시작하기

cmd를 열고 도움말을 보는 법, 그리고 거의 모든 명령에 함께 쓰는 연산자입니다.

실행과 도움말

  • Win+R → cmd 입력 후 Enter
  • 관리자 권한: 시작 메뉴에서 "명령 프롬프트"를 오른쪽 클릭 → 관리자 권한으로 실행
  • 명령별 도움말: <명령> /? (예: robocopy /?)
  • 기본 명령 목록: help
출처: Windows commands ↗

리디렉션과 파이프

  • > 출력을 파일로 (덮어쓰기), >> 이어 쓰기
  • < 파일을 입력으로
  • 2> 오류 출력 리디렉션, 2>&1 오류를 표준 출력에 합치기
  • | 앞 명령의 출력을 다음 명령 입력으로
  • && 앞이 성공하면 실행, || 실패하면 실행, & 순서대로 실행
출처: cmd ↗

와일드카드와 경로

  • * 임의 길이 문자, ? 한 글자
  • 공백이 있는 경로는 큰따옴표로 감싸기: "C:\Program Files"
  • %VAR% 환경 변수 참조 (예: %USERPROFILE%)

2. 핵심 명령

실무에서 가장 자주 쓰는 명령입니다. 자세한 옵션은 3번 표에서 행을 클릭해 확인하세요.

dir 파일

폴더의 파일·하위 폴더 목록. /s 하위 포함, /b 이름만, /a 숨김 포함.

cd 파일

현재 폴더 이동. 드라이브까지 바꾸려면 cd /d D:\work.

robocopy 파일

대용량·폴더 단위 복사와 동기화. 재시도와 로그를 지원해 xcopy보다 안정적입니다.

findstr 텍스트

파일에서 문자열·정규식 검색. Linux의 grep과 비슷하게 씁니다.

tasklist / taskkill 시스템

실행 중인 프로세스 확인과 강제 종료. taskkill /im notepad.exe /f.

ipconfig 네트워크

IP 구성 확인. /all 상세, /flushdns DNS 캐시 비우기.

ping 네트워크

대상 호스트 응답 확인. -t 계속, -n 횟수 지정.

netstat 네트워크

연결과 열린 포트 확인. netstat -ano로 포트를 쓰는 PID 찾기.

sfc 관리관리자

시스템 파일 무결성 검사·복구. sfc /scannow.

shutdown 시스템

종료·재시작 예약. shutdown /r /t 0 즉시 재시작.
