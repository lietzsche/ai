Claude Code CLI 명령어 정리

Anthropic의 claude CLI 서브커맨드, 시작 플래그, 대화형 슬래시 명령어를 공식 도움말과 문서 기준으로 정리했습니다.

조사일: 2026-11-09 · 출처: claude --help (v2.1.318 직접 확인) 및 code.claude.com 공식 문서

1. 시작하기

터미널에서 claude로 대화형 세션을 시작하거나, -p로 일회성 프롬프트를 실행합니다.

기본 실행 방식

claude                     # 대화형 세션 시작
claude "버그 원인 찾아줘"     # 초기 프롬프트와 함께 시작
claude -p "요약해줘"        # 비대화형 출력 후 종료
claude -c                  # 최근 대화 이어하기
claude -r                  # 이전 세션 선택해 재개
출처: CLI reference ↗

설정과 메모리 파일

  • CLAUDE.md: 프로젝트 루트 또는 .claude/CLAUDE.md에 두는 프로젝트 지침
  • ~/.claude/CLAUDE.md: 모든 프로젝트에 적용되는 전역 지침
  • .claude/settings.json: 프로젝트 공유 설정 (개인용은 settings.local.json)
  • .claude/skills/<name>/SKILL.md: 프로젝트 스킬 (/<name>으로 호출)
출처: Memory & CLAUDE.md ↗

권한 모드 (--permission-mode)

  • manual / 기본: 도구 실행·파일 수정 시 승인 요청
  • acceptEdits: 파일 편집은 자동 승인, 명령 실행은 확인
  • plan: 코드를 수정하지 않고 탐색·계획만 수립
  • auto: 자동 모드 규칙에 따라 안전성 판단 후 실행
  • bypassPermissions: 모든 권한 확인 생략 (--dangerously-skip-permissions)
출처: CLI reference ↗

대화형 단축키·입력 접두사

  • / 슬래시 명령·스킬 검색, @ 파일·경로 멘션
  • !명령 프롬프트에서 즉시 셸 명령 실행
  • Shift+Tab 권한 모드 순환 (일반 → acceptEdits → plan 등)
  • Esc 생성 중단, Esc 두 번 눌러 이전 메시지로 되감기
  • Ctrl+C 입력 취소, Ctrl+D 세션 종료

2. 핵심 명령

실무에서 가장 자주 쓰는 CLI 옵션과 대화형 슬래시 명령입니다.

claude -p CLI 플래그

비대화형(헤드리스) 모드로 응답만 출력하고 종료합니다. 파이프라인이나 CI 스크립트에 사용합니다.

claude -c / -r CLI 플래그

현재 폴더의 직전 대화를 이어가거나(-c), 목록에서 이전 세션을 골라 재개합니다(-r).

--dangerously-skip-permissions CLI 플래그주의

모든 권한 확인을 건너뛰는 YOLO 모드입니다. 격리된 컨테이너·샌드박스에서만 사용하세요.

claude mcp 서브커맨드

외부 도구를 연결하는 MCP 서버를 추가·목록 조회·삭제·인증합니다.

/init 슬래시

저장소 구조와 빌드·테스트 방식을 분석해 초기 CLAUDE.md 파일을 생성합니다.

/compact 슬래시

대화가 길어졌을 때 핵심 맥락만 남기고 요약해 컨텍스트 공간을 확보합니다.

/clear 슬래시

현재 세션의 대화 기록을 비우고 새 작업으로 깔끔하게 시작합니다.

/plan 슬래시

코드를 바로 고치지 않고 코드베이스를 분석해 실행 계획부터 세우도록 전환합니다.

/diff / /rewind 슬래시

변경 사항을 대화형 diff 뷰어로 검토하거나(/diff), 이전 체크포인트로 코드와 대화를 되돌립니다(/rewind).

/model / --effort 설정

사용 모델(sonnet, opus 등)과 추론 강도(low~max)를 조절합니다.

3. 전체 명령

서브커맨드, 시작 플래그, 대화형 슬래시 명령 전체 목록입니다. 서브커맨드·플래그는 claude --help(v2.1.318)에서 직접 확인했습니다.

행을 클릭하면 자세한 설명과 사용 예, 공식 문서 링크가 펼쳐집니다.

명령분류별칭·단축설명
claudeCLI 실행대화형 세션 시작 (초기 프롬프트 전달 가능)
claude agentsCLI 서브커맨드백그라운드 에이전트 세션 목록·관리
claude attach <id>CLI 서브커맨드백그라운드 세션을 현재 터미널에 연결
claude logs <id>CLI 서브커맨드백그라운드 세션의 최근 출력 확인
claude stop <id>CLI 서브커맨드kill백그라운드 세션 중지 (기록은 보존)
claude rm <id>CLI 서브커맨드백그라운드 세션과 안전한 워크트리 삭제
claude respawn [id]CLI 서브커맨드백그라운드 세션을 현재 버전으로 재시작
claude authCLI 서브커맨드로그인·로그아웃·인증 상태 확인
claude setup-tokenCLI 서브커맨드장기 인증 토큰 설정 (구독 필요)
claude auto-modeCLI 서브커맨드자동 모드 규칙 조회·검토·초기화
claude mcpCLI 서브커맨드MCP 서버 추가·조회·삭제·로그인·실행
claude pluginCLI 서브커맨드plugins플러그인 설치·삭제·활성화·검증·생성
claude ultrareview [target]CLI 서브커맨드클라우드 멀티 에이전트 코드 리뷰 실행
claude doctorCLI 서브커맨드설치·설정 상태 점검
claude updateCLI 서브커맨드upgrade최신 버전 확인 및 업데이트
claude install [target]CLI 서브커맨드네이티브 빌드 설치 (stable, latest 등)
claude import [source]CLI 서브커맨드다른 AI 코딩 에이전트 설정 가져오기
claude purge [path]CLI 서브커맨드프로젝트의 로컬 기록·캐시 데이터 삭제
--printCLI 플래그-p비대화형으로 응답만 출력하고 종료
--continueCLI 플래그-c현재 폴더의 가장 최근 대화 이어하기
--resume [value]CLI 플래그-r세션 ID·이름으로 재개하거나 선택기 열기
--fork-sessionCLI 플래그재개 시 기존 ID 대신 새 세션으로 분기
--name <name>CLI 플래그-n세션 표시 이름 지정
--backgroundCLI 플래그--bg세션을 백그라운드로 시작하고 ID 출력
--worktree [name]CLI 플래그-w세션용 새 git worktree 생성 후 시작
--tmuxCLI 플래그워크트리용 tmux 세션 함께 생성
--model <model>CLI 플래그세션 모델 지정 (sonnet, opus 등)
--fallback-model <model>CLI 플래그기본 모델 과부하 시 대체할 모델 지정
--effort <level>CLI 플래그추론 강도 설정 (low~max)
--permission-mode <mode>CLI 플래그세션 권한 모드 지정 (plan, auto 등)
--dangerously-skip-permissionsCLI 플래그모든 권한 확인 생략 (YOLO 모드)
--allowedTools <tools...>CLI 플래그--allowed-tools승인 없이 허용할 도구 목록 지정
--disallowedTools <tools...>CLI 플래그--disallowed-tools사용 금지할 도구 목록 지정
--tools <tools...>CLI 플래그내장 도구 중 활성화할 목록만 지정
--restrictedCLI 플래그명령 실행·웹 도구를 제한한 안전 모드
--safe-modeCLI 플래그모든 사용자화(CLAUDE.md, 훅, MCP 등) 비활성화
--bareCLI 플래그자동 탐색·훅·플러그인을 뺀 최소 모드
--add-dir <dirs...>CLI 플래그도구 접근을 허용할 추가 디렉터리 지정
--system-prompt <prompt>CLI 플래그세션 시스템 프롬프트 교체
--append-system-prompt <prompt>CLI 플래그기본 시스템 프롬프트 뒤에 내용 추가
--output-format <format>CLI 플래그-p 출력 형식 (text, json, stream-json)
--json-schema <schema>CLI 플래그-p에서 JSON 스키마에 맞춘 구조화 출력 강제
--max-budget-usd <amount>CLI 플래그-p 실행 시 최대 API 비용(USD) 제한
--mcp-config <configs...>CLI 플래그JSON 파일·문자열에서 MCP 서버 로드
--agent <agent>CLI 플래그현재 세션에 사용할 커스텀 에이전트 지정
--agents <json-or-file>CLI 플래그커스텀 서브에이전트를 JSON으로 정의
--plugin-dir <path>CLI 플래그이번 세션에만 지정 폴더·zip 플러그인 로드
--settings <file-or-json>CLI 플래그추가 설정 JSON 파일·문자열 로드
--ideCLI 플래그시작 시 열려 있는 IDE에 자동 연결
--chromeCLI 플래그Claude in Chrome 브라우저 연동 활성화
--desktopCLI 플래그터미널 대신 Claude Desktop 앱에서 열기
--cloud [value]CLI 플래그클라우드 세션 생성 또는 연결
--remote-control [name]CLI 플래그원격 제어를 켠 채 대화형 세션 시작
--from-pr [value]CLI 플래그특정 PR 번호·URL과 연결된 세션 재개
--debug [filter]CLI 플래그-d디버그 모드 활성화 (카테고리 필터 지원)
/init슬래시 명령코드베이스를 분석해 CLAUDE.md 초안 생성
/compact [instructions]슬래시 명령대화 내용을 요약해 컨텍스트 여유 확보
/clear슬래시 명령/reset, /new대화 기록 초기화
/plan슬래시 명령코드 수정 없이 계획 모드로 전환
/model [model]슬래시 명령사용할 AI 모델 변경
/resume [session]슬래시 명령이전 대화 세션 불러오기
/rewind슬래시 명령이전 체크포인트로 대화와 코드 되돌리기
/diff슬래시 명령세션 중 변경된 코드 diff 뷰어 열기
/btw <question>슬래시 명령메인 기록에 남기지 않는 곁가지 질문
/memory슬래시 명령CLAUDE.md 메모리 파일 확인·편집
/config슬래시 명령설정 인터페이스 열기 (테마, 에디터 모드 등)
/permissions슬래시 명령도구 실행 허용·거부 권한 규칙 관리
/mcp슬래시 명령MCP 서버 연결 상태 확인·관리
/agents슬래시 명령커스텀 서브에이전트 확인·생성·관리
/hooks슬래시 명령라이프사이클 훅 설정 확인·관리
/context슬래시 명령컨텍스트 윈도우 사용량 시각화
/cost슬래시 명령현재 세션 토큰 사용량·예상 비용 확인
/usage슬래시 명령구독 플랜 사용량 한도 확인
/status슬래시 명령버전, 모델, 계정, 연결 상태 확인
/doctor슬래시 명령설치·설정 문제를 진단하고 수정 안내
/code-review슬래시 명령현재 브랜치 변경 사항 코드 리뷰
/bug슬래시 명령Anthropic에 버그 리포트 전송
/help슬래시 명령사용 가능한 명령어·스킬 도움말 표시

여기에 더해 .claude/skills/<name>/SKILL.md에 추가한 스킬마다 /<name> 슬래시 명령이 자동으로 등록됩니다.
