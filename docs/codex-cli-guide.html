OpenAI Codex CLI 명령어 정리

OpenAI의 codex CLI 서브커맨드, 시작 플래그, 대화형 슬래시 명령어와 스킬·멘션 문법을 공식 도움말과 문서 기준으로 정리했습니다.

조사일: 2026-11-09 · 출처: codex --help (v0.166.0 직접 확인) 및 developers.openai.com/codex 공식 문서
1. 시작하기 2. 핵심 명령 3. 전체 명령

1. 시작하기

터미널에서 codex로 대화형 TUI를 시작하거나, codex exec(별칭 e)로 비대화형 작업을 실행합니다.

기본 실행 방식

codex                        # 대화형 TUI 세션 시작
codex "실패 테스트 원인 찾아줘"  # 초기 프롬프트와 함께 시작
codex exec "변경사항 요약해줘"   # 비대화형 실행 후 종료 (별칭: e)
codex resume --last          # 가장 최근 대화 이어하기
codex fork --last            # 최근 대화를 새 스레드로 분기
출처: Codex CLI ↗

지침(AGENTS.md), 스킬, 설정 파일

  • AGENTS.md: 저장소 루트·하위 폴더에서 읽는 프로젝트 규칙과 지침
  • .agents/skills/<name>/SKILL.md: 프로젝트 스킬 ($<name> 또는 /skills로 호출)
  • ~/.codex/config.toml: 모델·샌드박스·MCP 서버 등 전역 설정 파일
  • -c key=value: 실행 시점에 config.toml 값을 인라인으로 덮어쓰기
출처: Codex CLI configuration ↗

샌드박스(-s)와 승인 정책(-a)

  • -s read-only: 파일 수정 없이 읽기 전용으로 탐색
  • -s workspace-write: 현재 워크스페이스 폴더 내 파일 쓰기 허용
  • -s danger-full-access: 샌드박스 파일·네트워크 격리 해제
  • -a on-request / never: 승인 요청 시점 제어 (--approve-for-me는 자동 검토)
  • --dangerously-bypass-approvals-and-sandbox: 모든 승인·샌드박스 해제 (네이티브 YOLO 모드)
출처: Sandbox & approvals ↗

대화형 단축키·입력 접두사

  • / 슬래시 명령 검색 및 실행, $<skill-name> 스킬 직접 호출
  • @경로 퍼지 검색으로 프로젝트 파일·폴더를 컨텍스트에 첨부
  • 작업 실행 중 메시지 입력 후 Tab: 다음 턴 대기열(큐)에 지시 추가
  • Ctrl+C 현재 작업 취소 및 종료, /exit(/quit) 세션 종료
출처: Interactive TUI ↗

2. 핵심 명령

실무 개발, 코드 리뷰, 세션 관리, 권한 제어에서 가장 자주 쓰는 서브커맨드와 슬래시 명령입니다.

codex exec 서브커맨드

TUI 없이 단일 프롬프트를 끝까지 실행합니다(별칭 codex e). --json, --ephemeral, -o <FILE>과 함께 CI·스크립트에 씁니다.

codex review 서브커맨드

미커밋 변경분(--uncommitted), 기준 브랜치 대비 변경분(--base), 특정 커밋(--commit)을 비대화형으로 코드 리뷰합니다.

codex resume / fork 서브커맨드

이전 세션을 이어서 진행하거나(resume), 기존 대화 맥락을 복제해 새 스레드로 분기합니다(fork). --last로 직전 세션을 바로 엽니다.

--dangerously-bypass-approvals-and-sandbox CLI 플래그주의

승인 확인과 OS 샌드박스를 모두 건너뛰는 네이티브 YOLO 모드입니다. 외부와 격리된 컨테이너·VM에서만 사용하세요.

-s / -a / --approve-for-me CLI 플래그

샌드박스 범위(-s)와 승인 정책(-a)을 조합하거나, --approve-for-me로 workspace-write 안에서 자동 승인 검토를 활성화합니다.

codex apply 서브커맨드

에이전트가 생성한 최신 diff 패치를 로컬 Git 작업 트리에 git apply로 즉시 반영합니다 (별칭 codex a).

codex mcp 서브커맨드

외부 도구를 연결하는 MCP 서버를 조회(list), 추가(add), 삭제(remove), 인증(login)합니다.

/plan 슬래시

코드를 바로 수정하지 않고 요구사항 분석과 단계별 실행 계획을 먼저 수립하는 모드로 전환합니다.

/review / /diff 슬래시

대화형 세션 안에서 현재 작업 트리의 변경분을 점검해 코드 리뷰를 받거나(/review), 추적되지 않는 파일을 포함한 Git diff를 확인합니다(/diff).

/skills / $<skill> 스킬

.agents/skills/<name>/SKILL.md 스킬 목록을 열어 선택하거나(/skills), 프롬프트에서 $<skill-name>으로 직접 호출합니다.

3. 전체 명령

서브커맨드, 시작 플래그, 대화형 슬래시 명령 및 멘션 전체 목록입니다. 서브커맨드·플래그는 로컬 codex --help(v0.166.0)에서 직접 확인했습니다.

행을 클릭하면 자세한 설명과 사용 예, 공식 문서 링크가 펼쳐집니다.

명령분류별칭·단축설명
codex [PROMPT]CLI 실행대화형 TUI 세션 시작 (초기 프롬프트 전달 가능)
codex exec [PROMPT]CLI 서브커맨드e비대화형(헤드리스)으로 작업 실행 (resume, fork, review 하위 명령 포함)
codex reviewCLI 서브커맨드비대화형으로 미커밋·브랜치·커밋 단위 코드 리뷰 실행
codex resume [SESSION_ID]CLI 서브커맨드이전 대화형 세션을 선택하거나 --last로 직전 세션 재개
codex fork [SESSION_ID]CLI 서브커맨드이전 대화형 세션을 새로운 스레드로 복제·분기
codex apply <TASK_ID>CLI 서브커맨드a에이전트가 생성한 최신 diff를 로컬 작업 트리에 git apply로 반영
codex agentsCLI 서브커맨드공유 로컬 앱 서버 데몬의 모든 에이전트 세션 탐색
codex queueCLI 서브커맨드실행 중인 기존 세션에 후속 메시지를 대기열(큐)로 추가
codex archiveCLI 서브커맨드저장된 세션을 ID 또는 세션 이름으로 보관(아카이브) 처리
codex unarchiveCLI 서브커맨드보관(아카이브)된 세션을 다시 활성 목록으로 복원
codex deleteCLI 서브커맨드저장된 세션을 ID 또는 세션 이름으로 영구 삭제
codex mcpCLI 서브커맨드외부 MCP 서버 관리 (list, get, add, remove, login, logout)
codex pluginCLI 서브커맨드플러그인 및 마켓플레이스 관리 (list, add, remove, marketplace)
codex cloudCLI 서브커맨드cloud-tasks[실험] Codex Cloud 태스크 조회·실행·diff 확인 및 로컬 반영
codex sandboxCLI 서브커맨드debugCodex가 제공하는 OS 샌드박스 안에서 임의 명령 실행
codex featuresCLI 서브커맨드기능 플래그(Feature Flags) 상태 조회 및 영구 활성화·비활성화
codex loginCLI 서브커맨드ChatGPT OAuth·디바이스 코드·API 키로 인증 로그인
codex logoutCLI 서브커맨드로컬에 저장된 모든 인증 자격 증명 삭제
codex doctorCLI 서브커맨드로컬 설치, config.toml, 인증, 런타임 상태 진단
codex updateCLI 서브커맨드Codex CLI를 최신 버전으로 업데이트
codex app [PATH]CLI 서브커맨드Codex 데스크톱 앱 실행 및 지정 워크스페이스 열기
codex app-serverCLI 서브커맨드[실험] 로컬 앱 서버 데몬 실행
codex remote-controlCLI 서브커맨드[실험] 원격 제어용 로컬 앱 서버 실행
codex exec-serverCLI 서브커맨드[실험] 원격 실행 환경용 exec 서버 데몬 실행
codex completion [SHELL]CLI 서브커맨드bash, zsh, fish, powershell 자동완성 스크립트 생성
--model <MODEL>CLI 플래그-m에이전트가 사용할 모델 지정 (예: gpt-5-codex, o3)
--sandbox <MODE>CLI 플래그-s셸 명령 실행 샌드박스 정책 (read-only, workspace-write, danger-full-access)
--ask-for-approval <POLICY>CLI 플래그-a명령 실행 전 사용자 승인 요청 시점 (on-request, never)
--approve-for-meCLI 플래그workspace-write 샌드박스를 쓰며 승인 요청을 자동 검토기로 라우팅
--dangerously-bypass-approvals-and-sandboxCLI 플래그모든 승인 확인을 건너뛰고 샌드박스 없이 실행 (네이티브 YOLO 모드)
--dangerously-bypass-hook-trustCLI 플래그저장된 훅 신뢰 확인 없이 활성화된 훅 실행
--config <key=value>CLI 플래그-c~/.codex/config.toml 설정값을 실행 시점에 덮어쓰기
--strict-configCLI 플래그config.toml에 알 수 없는 필드가 있으면 경고 대신 즉시 오류 발생
--profile <PROFILE>CLI 플래그-p$CODEX_HOME/<name>.config.toml 또는 프로필 설정 레이어 로드
--enable <FEATURE>CLI 플래그이번 실행 세션에서 특정 기능 플래그 활성화
--disable <FEATURE>CLI 플래그이번 실행 세션에서 특정 기능 플래그 비활성화
--cd <DIR>CLI 플래그-C에이전트의 작업 기준 루트 디렉터리 지정
--worktree [NAME]CLI 플래그새 관리형 Git worktree를 생성하고 그 안에서 독립 세션 실행
--add-dir <DIR>CLI 플래그기본 워크스페이스 외에 쓰기 권한을 허용할 추가 디렉터리 지정
--image <FILE>CLI 플래그-i초기 프롬프트에 하나 이상의 이미지 파일 첨부
--searchCLI 플래그실시간 웹 검색 도구(web_search) 활성화
--ossCLI 플래그로컬 오픈소스 모델 프로바이더(LM Studio·Ollama) 사용
--local-provider <PROVIDER>CLI 플래그--oss 실행 시 사용할 로컬 프로바이더 지정 (lmstudio 또는 ollama)
--remote <ADDR>CLI 플래그원격 앱 서버(ws:// 또는 wss://)에 TUI 연결
--no-alt-screenCLI 플래그대체 화면 버퍼 없이 인라인 모드로 TUI를 실행해 터미널 스크롤백 유지
--no-daemonCLI 플래그공유 백그라운드 서버 데몬 없이 인프로세스로 직접 실행
--jsonexec 전용 플래그codex exec 실행 이벤트를 JSONL 스트림으로 표준 출력에 기록
--output-last-message <FILE>exec 전용 플래그-ocodex exec에서 에이전트의 마지막 응답 메시지를 지정 파일에 저장
--output-schema <FILE>exec 전용 플래그codex exec 최종 응답이 따를 JSON Schema 파일 지정
--ephemeralexec 전용 플래그codex exec 실행 시 세션 기록 파일을 디스크에 저장하지 않음
--skip-git-repo-checkexec 전용 플래그Git 저장소가 아닌 일반 폴더에서도 codex exec 실행 허용
/model대화형 슬래시활성 모델 및 추론 강도(Reasoning Effort) 확인·변경
/permissions대화형 슬래시/approvals대화 도중 샌드박스 모드와 승인 요청 정책 전환
/plan대화형 슬래시코드를 수정하기 전에 설계와 단계별 실행 계획부터 수립
/review대화형 슬래시현재 작업 트리·브랜치 변경사항에 대한 코드 리뷰 수행
/diff대화형 슬래시추적되지 않는 새 파일을 포함한 현재 Git diff 확인
/skills대화형 슬래시로드된 스킬(.agents/skills/<name>/SKILL.md) 목록 탐색 및 실행
$<skill-name>대화형 멘션프롬프트에서 특정 스킬을 이름으로 즉시 호출
@<path>대화형 멘션프로젝트 파일·폴더 경로를 검색해 프롬프트 컨텍스트에 첨부
/compact대화형 슬래시대화 내역을 핵심 요약으로 압축해 컨텍스트 여유 토큰 확보
/clear대화형 슬래시/new현재 대화 기록을 비우고 새 대화 세션 시작
/resume대화형 슬래시저장된 이전 대화 목록을 열어 세션 전환
/fork대화형 슬래시현재 진행 중인 대화를 새로운 세션 스레드로 복제·분기
/mcp대화형 슬래시현재 연결된 MCP 서버 및 제공 도구 상태 확인
/status대화형 슬래시현재 세션 ID, 모델, 권한·샌드박스 정책, 토큰 사용량 표시
/init대화형 슬래시저장소 분석 후 프로젝트 지침 파일 AGENTS.md 초안 생성
/help대화형 슬래시사용 가능한 슬래시 명령어와 단축키 안내 표시
/exit대화형 슬래시/quit대화형 TUI 세션 종료
