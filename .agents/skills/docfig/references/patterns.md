# 도식별 설계 패턴과 데이터 모양 (`compare` · `matrix` · `network`)

`Flow`만으로 그리기 어려운 **전환 대조**, **2축 다대다 교차**, **다층 초점 관계망**의 구체적인 사용 패턴을 정리한다. 특정 분야(DB·코드·에세이·정책 등)의 용어나 화면 틀에 얽매이지 않고, **보여 줄 관계의 위상(Topology)**에 맞춰 고른다.

## 1. 대립·전환 대조도 (`compare`)

기존 방식·통념·문제가 **어떤 계기(메커니즘)**를 거쳐 새로운 구조·원리·해법으로 바뀌는지 1:1 짝으로 대비할 때 쓴다(순수 정적 SVG).

```python
from figlib import compare, figure

pairs = [
    # (왼쪽 제목, 왼쪽 보조 설명, 오른쪽 제목, 오른쪽 보조 설명, 가운데 전환 동사/계기)
    ('수동 배포 스크립트', '담당자 기억에 의존해 누락 발생', '선언형 파이프라인', '검증 통과 시에만 자동 반영', '검증 코드화'),
    ('장애 후 로그 수색', '원인 파악까지 수십 분 소요', '구조화 추적 ID', '요청 단위로 병목 구간 즉시 특정', '진입점 ID 주입'),
]
svg = compare(
    pairs,
    label='수동 운영에서 선언형 자동 검증 체계로의 전환 대조도',
    mid='cmp1',
    left_head=('변경 전 · 한계', '병목·오류 원인'),
    right_head=('변경 후 · 해법', '개선된 작동 원리'),
    via_head='전환 메커니즘',
)
html = figure(svg, '왼쪽의 운영 병목(점선)이 가운데 전환 장치를 통해 오른쪽 구조(초록 막대)로 해소된다.', 'fig-shift')
```

## 2. 2축 매핑·상관 격자 (`matrix`)

두 축 사이의 **다대다 관계**(개념 × 개념 상관도, 단계 × 대상 관여도, 환경 × 정책 차이 등)를 선으로 이으면 거미줄이 된다. 이럴 때는 행×열 교차 격자로 밀도와 역할을 한눈에 대조한다(순수 정적 SVG).

```python
from figlib import matrix, figure

cols = [('정확성 검증', '사실·인과 확립'), ('추론 가공', '가설 수정'), ('실천 조율', '현장 적용')]
groups = [
    ('초기 한계\n2항목', [
        # (행 이름, 보조 설명, 주의막대 여부, {열번호: (칸종류, '칸 문구')})
        ('확증 편향', '반례 무시', False, {0: ('strong', '반증 대조'), 1: ('rel', '가설 재설정')}),
        ('관성적 반복', '기억 의존', True,  {1: ('strong', '조건 분해'), 2: ('pos', '단위 실험')}),
    ]),
]
svg = matrix(
    cols, groups,
    label='한계 요인별 해결 원리 상관 격자',
    mid='mtx1',
    legend=[('strong', '핵심 전환 축'), ('rel', '보조 연관'), ('pos', '도달 해법')],
)
```

- **칸 종류(`CELL`)**:
  - 범용: `strong`(강한 상관·핵심), `rel`(보조·연관), `pos`(해법·달성), `warn`(주의·긴장), `gap`(단절·미해결 점선), `empty`(빈 자리)
  - 기술 문서 호환 별칭: `w`(씀), `rw`(읽고 씀), `r`(읽음), `h`(사람 개입), `ok`(완료), `f`(미구현), `c`(자리만)

## 3. 다층 초점 관계망 (`network`)

노드가 **12~40개 안팎**이고 **3~6개 단계(층)**를 가로지르며 여러 갈래로 이어져, 정적 선만으로는 복잡해질 때 쓴다.

- **핵심 원리**:
  - 처음에는 모든 노드의 **제목과 한 줄 요약**, 그리고 **연한 골격선(`opacity 0.36`)**만 본문 폭에 맞춰 차분하게 보여 준다.
  - 독자가 범주 필터를 고르거나 특정 노드를 클릭하면 BFS로 **선행 요인(원인·전제, 초록)**과 **후행 귀결(결과·파급, 파랑)**만 끝까지 밝히고, 그림 바로 아래 인라인 상자에 상세 설명과 연결 노드 이동 칩을 보여 준다(화면을 가리는 고정 팝업이나 별도 탭을 강제하지 않음).
  - 모든 간선은 왼쪽 단계 → 오른쪽 단계(같은 단계 안에서는 위 → 아래) **단방향**으로만 배치한다(`check`가 역방향 간선과 7단계 초과를 검사함).

```python
from figlib import network

net_html = network(
    {
        'stages': [
            ('1 · 발생 조건', '문제·자극 기점'),
            ('2 · 매개 메커니즘', '증폭 또는 걸러냄'),
            ('3 · 최종 귀결', '나타나는 현상·해법'),
        ],
        'nodes': [
            {
                'id': 'n1', 'stage': 0, 'tone': 'neutral', 'group': '인지',
                'title': '불확실성 직면', 'badge': '기점',
                'summary': '예측 불가능한 상황 발생',
                'detail': '기존 경험만으로 판단할 수 없는 낯선 조건이 주어지는 출발점이다.',
            },
            {
                'id': 'n2', 'stage': 1, 'tone': 'accent', 'group': '인지',
                'title': '인과 가설 분리',
                'summary': '확실한 사실과 미지수 구분',
                'detail': '감정적 단정을 멈추고 확인된 사실과 검증할 가설을 분리한다.',
            },
            {
                'id': 'n3', 'stage': 2, 'tone': 'ok', 'group': '실천',
                'title': '단위 검증 실행', 'badge': '해법',
                'summary': '작은 범위에서 실험·보정',
                'detail': '전체 완결 환상 대신 검증 가능한 단위부터 실행해 결과를 반영한다.',
            },
        ],
        # [선행ID, 후행ID] 또는 [선행ID, 후행ID, '간선 동작 라벨', 점선여부]
        'edges': [
            ['n1', 'n2', '사실 분할'],
            ['n2', 'n3', '검증 적용'],
        ],
    },
    caption='노드를 클릭하면 그 노드를 낳은 선행 전제(초록)와 거기서 파생되는 후행 귀결(파랑)이 끝까지 강조됩니다.',
    fid='fig-concept-net',
    up_label='선행 전제 · 원인',
    down_label='후행 파급 · 귀결',
)
```
