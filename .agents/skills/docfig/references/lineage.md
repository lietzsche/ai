## 1. 왜 정적 그림이나 전체 펼침 대신 `lineage`를 쓰는가

표 30개·열 500개를 한 화면에 전부 펼쳐 선을 다 그으면 가로 6,000px짜리 거미줄이 되어 읽을 수 없다. 읽기 쉬운 연결도는 다섯 가지를 지킨다.

1. **의미 레인(4~7줄)과 부제**: 시트 번호(`G01~G33`) 묶음이 아니라 **처리 층과 줄이 생기는 계기(주기)**로 레인을 나누고, 각 레인 머리말에 "이 줄이 언제·무엇을 하는지" 부제를 붙인다(예: `gold ① 기준 정보 · 사건` / `기록이 들어올 때 한 줄`).
2. **단방향 위상 정렬(역방향 간선 0개)**: 읽히는 방향이 늘 **왼쪽 → 오른쪽**(같은 레인 안에서는 위 → 아래)이 되도록 놓는다. 순환 참조가 보이면 번호부(앞)와 요약 열(조립 뒤)처럼 단계로 갈라 단방향으로 편다.
3. **점진적 노출(`키만` 기본)**: 처음에는 각 상자에 **키(PK) 열과 요약 1줄**(`그 밖 입력 5 · 계산 8`, `쓰는 열 6 · 전체 16`)만 보여 준다(열이 8개 이하인 핵심 추론 표만 예외로 상시 표시). 전체 열은 `키만 / 전부` 토글이나 표·열 클릭 때만 펼친다.
4. **2단계 연결선과 상·하류 색 구분**:
   - 평상시: **표↔표 골격선만 연하게(`opacity 0.42`)** 깔고 열↔열 선은 숨긴다.
   - 마우스 올림(호버): 직접 이어진 1단계 이웃 표만 미리 강조한다.
   - 클릭(고정): BFS로 **읽는 쪽(상류 = 초록)**과 **읽히는 쪽(하류 = 파랑)**을 **끝까지(추이 폐포)** 추적하며, 그때만 **열↔열 계보선**을 그린다.
5. **상류 평균 Y 정렬과 절제된 부호**: 둘째 레인부터는 읽는 상류 표들의 평균 Y 좌표보다 위로 올라가지 않게 배치해 선을 짧고 수평에 가깝게 유지한다. 원색 배지 남발 대신 **머리말 왼쪽 4px 색 막대**(층 구분), **점선 테두리**(아직 없는 표·계획), **작은 경고 점**(재료 열 미정)만 쓴다.

## 3. 본문과 탭으로 분리하기 (`tab_wrap`)

본문이 긴 설계 문서(최대 폭 ~1,100px)에 5~7레인짜리 대형 연결도를 본문 중간에 그대로 끼우면 글 흐름이 끊긴다. 이럴 때는:

1. **본문 맨 앞(요약 절)**에는 `Flow` + `card`로 **4~5칸짜리 한 장 요약 흐름도**만 두어 큰 방향을 10초 안에 이해시킨다.
2. 상세 표·열 연결도는 `tab_wrap(doc_html, fig_html, doc_label='설계 문서', fig_label='연결도', tab_id='erd')`로 감싸 상단 탭(`설계 문서` | `연결도`)으로 분리한다(`default_fit=False` 또는 `True` 모두 가능, `.df-wide`가 최대 2,000px 폭을 확보함).
3. 본문 안에서 `<a href="#erd">연결도 탭</a>`이나 `<a href="#erd?pin=고객 현황">고객 현황 연결 보기</a>`로 링크하면 클릭 즉시 `연결도` 탭으로 전환되며 해당 표·열이 선택된다.

## 4. 주소(해시) 공유와 키보드 조작

- **딥링크 주소 규칙**:
  - 탭 전환: `#erd`
  - 특정 표 고정 + 상세 패널 열기: `#erd?pin=고객 현황` (단독 그림이면 `#fig-erd?pin=고객 현황`)
  - 특정 열 계보 추적: `#erd?col=고객 현황::consult_cnt_6m`
  - 원천 묶음 파급 보기: `#erd?src=C-Cube`
  - 전체 열 펼침·한눈에 보기 조합: `#erd?mode=all&fit=1`
- **키보드 조작**:
  - `Tab`으로 상자·버튼 이동, `Enter` 또는 `Space`로 표 선택/해제, `Escape`로 상세 패널 닫기·선택 초기화.

## 5. 점검 항목과 피해야 할 안티패턴

`python .agents/skills/docfig/scripts/figlib.py check <문서.html>` 실행 시 아래 항목을 자동 검사한다.

- **레인 과다(8개 초과)**: 시트 번호순으로 10~12줄을 늘어놓지 말고 층·갱신 계기로 4~7줄 이내로 묶는다.
- **역방향 간선(`lane[원천] > lane[대상]`)**: 오른쪽에서 왼쪽으로 거슬러 가는 간선이 있으면 레인 배치를 고치거나 순환 참조를 단계로 가른다.
- **참조 무결성**: 존재하지 않는 표 ID나 열 이름을 가리키는 간선·`s` 참조가 없는지 확인한다.
- **외부 의존성 0개**: 웹폰트(`fonts.googleapis.com`)나 외부 CDN 스크립트를 넣지 않는다.
