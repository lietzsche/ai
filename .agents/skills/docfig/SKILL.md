# docfig — 문서를 한눈에 읽히게 하는 도식 설계

**핵심 원칙 (IRON LAW)**:
1. 특정 문서의 화면 틀(전용 탭 이름·DB 열쇠 아이콘·고정 팝업 등)을 다른 주제의 문서에 복제하지 않는다. 주제의 어휘와 관계 위상에 맞는 도식을 고른다.
2. 호버(마우스 가리킴) 때 다른 카드를 흐리게 지우지 않는다(비연관 카드 `opacity 1` 유지, 연결선과 직접 이웃 테두리만 강조). 클릭 고정·필터 때도 비연관 카드는 맥락 대조가 가능한 가독 수준(`opacity ≥ 0.5`)을 유지한다.
3. `python3 .agents/skills/docfig/scripts/figlib.py check <문서.html>` 통과 전에는 작업을 완료로 보고하지 않는다.

글로 길게 조립해야만 머릿속에 그려지는 **인과·흐름·대립·상관관계·계층 구조**를 외부 의존성 없는 인라인 SVG 도식으로 설계해 HTML 문서에 넣는다. 외부 라이브러리·웹폰트·이미지를 쓰지 않아 오프라인·폐쇄망 환경에서도 그대로 열린다. 보조 도구는 [scripts/figlib.py](./scripts/figlib.py)이며, 사용자의 언어로 대화한다.

## 진행 체크리스트

```text

  - [ ] 4.2 안전한 고정 프로필 브라우저가 있으면 `figlib.py shot` 확인, 없으면 미실행 사유 기록
```

## 1. 그릴지 말지

- 그림은 **여러 요소의 관계·분기·상관성을 한눈에 보여 줄 때**만 넣는다. 한 문장이면 끝나는 사실은 글로 둔다.
- **명사 나열이 아니라 작동 원리(메커니즘)를 그린다.** 상자 이름만 늘어놓지 말고, 무엇이 어떤 조건·계기를 통해 무엇을 낳거나 깨뜨리는지 화살표 동사로 적는다.
- **실재·확정과 가설·위험·미구현을 모양으로 가른다.** 작동 중인 경로·확립된 원리는 실선으로, 아직 없는 연결·오류 함정·가설은 점선(`gap`, `dashed=True`)으로 구분한다.
- 그림은 **구조적 통찰**을 맡고, 정확한 정의·수치·원문 근거는 표와 본문이 맡도록 역할을 나눈다.

## 2. 관계 모양(위상)에 따라 어떤 도식을 쓸지

분석한 관계의 위상에 맞춰 도식을 고른다(`compare`·`matrix`·`network`의 데이터 구조와 호출 예시는 Step 2에서 [references/patterns.md](./references/patterns.md)를 로드해 확인).

| 보여 줄 관계의 모양 | 적합한 도식 | `figlib` 도구 |
| --- | --- | --- |
| 순차 처리, 조건 분기, 선순환 vs 악순환 회로 (상자 ~12개 이내) | 흐름·회로도 (정적 SVG) | `Flow` + `lane`·`card`(`box`)·`arrow`·`note` |
| 기존 통념 ↔ 재정의, 변경 전(AS-IS) ↔ 변경 후(TO-BE) 1:1 전환 | 전환 대조도 (정적 SVG) | `compare` |
| 두 축 사이의 다대다 상관관계·관여도·역할 비교 | 매핑·상관 격자 (정적 SVG) | `matrix` |
| 3~6단계에 걸친 12~40개 노드의 다중 인과·파급 사슬 | 초점 관계망 (선택 강조형) | `network` |

## 3. 읽기 쉬운 도식의 6원칙

1. **거시 먼저, 세부는 점진적으로 (정보 밀도 제어)**:
   - 처음부터 수십 개 상자와 수백 개 세부 속성을 한 화면에 다 펼쳐 놓지 않는다.
   - 문서 첫머리에 **5~8개 핵심 묶음 이내의 거시 도식**으로 전체 작동 원리를 10초 안에 이해시키고, 세부 항목은 절별 소형 도식·요약 표·접기(`<details>`)·선택 강조로 단계화한다. 상자 하나에는 **제목 + 핵심 요지 1~2줄**만 담는다.
2. **배치 축 = 논리 축, 단방향 질서 (역방향 간선 0개)**:
   - 일련번호나 나열 순서대로 여러 줄에 쪼개 놓지 않는다. **원인 → 매개 → 귀결**, **입력 → 변환 → 출력**, **문제 → 해체 → 해법**처럼 위치 자체가 의미를 갖도록 3~6개 이내의 단계 축을 세우고 머리말(`lane` / `stages`)에 기준을 적는다.
   - 양방향·순환처럼 보이는 관계도 선행 조건과 후행 결과로 분해해 **왼쪽 → 오른쪽**(같은 열에서는 위 → 아래) 한 방향으로 편다. 양끝 동그라미 대신 분명한 삼각형 화살촉을 쓴다.
3. **연결 대상을 같은 높이에 정렬**:
   - 둘째 열부터 무작정 맨 위(`y=0`)에서 쌓지 않고, 연결된 왼쪽 선행 상자들의 높이 근처에 맞춰 대각선·계단식 장거리 교차선을 줄인다(`network`는 자동 정렬).
4. **바탕은 조용하게, 강조는 얇은 색 막대로 절제**:
   - 바탕은 중립 표면(`--fg-panel`)으로 통일하고, 범주 차이는 **왼쪽 4px 색 막대(최대 4색)**와 **실선/점선 테두리**로만 차분하게 구분한다. 색은 `figlib` 전용 변수(`--fg-*`, 밝은·어두운 화면 자동 대응)만 쓴다.
5. **선이 많아질 때는 골격·호버·고정 3단계를 분리 (`network`)**:
   - **평상시**: 모든 노드를 또렷하게 두되 연결선은 연한 골격선(`opacity 0.38`)만 깔아 시야를 어지럽히지 않는다.
   - **호버(가리킴)**: 주변 카드를 흐리게 지우지 않고(`opacity 1` 유지), 가리킨 카드와 직접 닿은 **1단계 선행(초록)·후행(파랑) 간선과 이웃 테두리**만 밝혀 전체 맥락 속에서 관계를 읽게 한다.
   - **클릭 고정·범주 필터**: 선택한 노드의 전체 선행 요인(초록)·후행 파급(파랑) 사슬을 끝까지 추적하고 하단에 상세 설명을 열되, 비연관 카드도 제목·요약을 읽을 수 있는 수준(`opacity 0.55`)으로만 낮춘다.
6. **캡션에 '이름'이 아니라 '통찰'을 적는다**:
   - `<figcaption>`에는 "○○ 구조도" 같은 제목 반복 대신, **이 도식에서 읽어야 할 핵심 상관관계·결론 한두 문장**을 적는다. 비밀정보·토큰·비공개 주소·민감 개인정보는 절대 그리지 않는다.

## 4. 모양과 색 부호

| 의미 | `Flow.card` / `network` (`tone`) | `Flow.box` (`kind`) | `matrix` 칸 |
| --- | --- | --- | --- |
| 기점·원천·기본 대상 | `'neutral'` (회색 막대) | `'item'` | `'rel'` / `'r'` (연관·읽음) |
| 핵심 메커니즘·처리·강한 상관 | `'accent'` (파랑 막대) | `'step'` / `'llm'` | `'strong'` / `'w'` (핵심·씀) |
| 전환점·주의·사람 개입 | `'warn'` (주황 막대) | `'person'` / `'pii'` | `'warn'` / `'h'` (긴장·수동) |
| 해법·도달점·성립 | `'ok'` (초록 막대) | `'ok'` | `'pos'` / `'ok'` (해법·완료) |
| 함정·단절·가설·미구현 | `'gap'` 또는 `dashed=True` (점선) | `'gap'` | `'gap'` / `'f'` (점선), `'empty'` |

## 5. 스크립트 실행과 검증

임시 폴더(scratch 또는 OS 임시 폴더)에서 생성 스크립트를 실행하고 점검한다(`figlib.py` 자체는 컨텍스트에 통째로 읽지 않고 모듈로 임포트해 실행한다).

```python
import sys
sys.path.insert(0, '.agents/skills/docfig/scripts')
from figlib import Flow, compare, matrix, network, figure, Doc

d = Doc('docs/<문서>.html')
d.insert_before('<h2 id="s2">', figure(svg, '도식이 보여 주는 핵심 통찰', 'fig-xxx'))
# 대상 문서가 '버전 x.y'와 '변경 이력' 표·archive/ 보관을 쓰는 경우에만 선택 호출:
# d.bump('그림 추가: …', date='YYYY-MM-DD')
d.save()  # 기존 문서에 예전 docfig-net 스타일·스크립트가 있으면 최신 판으로 자동 갱신됨
```

```bash
python3 .agents/skills/docfig/scripts/figlib.py check docs/<문서>.html
python3 .agents/skills/docfig/scripts/figlib.py shot  docs/<문서>.html <임시폴더>
```

- `check`는 외부 의존성, `aria-label`, `figcaption`, 중복 ID, **정적 SVG의 `viewBox` 밖 글자 잘림**, **`network`의 단계 과다(7개 초과)·역방향 간선·비연관 카드 과도한 흐림(`opacity < 0.4`)**, 깨진 링크·앵커를 자동 검사한다.
- Windows에서 Chrome·Edge를 임시 프로필로 반복 실행하면 빈 암호 확인(`LogonUserW`, 이벤트 4625) 누적으로 OS 계정이 잠길 수 있다. 스크린샷은 고정 프로필을 재사용하는 `figlib.py shot`으로만 직렬 실행하며, 안전한 브라우저 실행 경로가 없는 환경에서는 우회하지 않고 `shot` 미실행 사실을 정직하게 보고한다.

## 6. 금지 패턴 (Anti-Patterns)

- **특정 주제의 화면 틀 복제**: 이전 문서에서 썼던 탭 구성, DB 전용 열쇠 아이콘, 화면을 가리는 고정 팝업 등을 다른 주제의 문서에 그대로 베끼지 않는다.
- **호버 시 주변 카드 증발 (`opacity < 0.4`)**: 마우스를 올렸다는 이유만으로 다른 카드를 `0.1~0.2` 투명도로 지워 버리면 전체 구조 맥락이 끊기고 화면이 깜빡인다. 호버는 연결선·이웃 강조만 수행하고 주변 카드를 그대로 읽히게 둔다.
- **의미 축 없는 번호순 나열 + 거미줄 간선**: 수십 개 항목을 번호순으로 늘어놓고 선을 다 긋지 않는다. 3~6개 의미 축으로 묶고 2축 다대다는 `matrix`, 다단계 파급은 `network`, 1:1 전환은 `compare`로 분리한다.
- **경계 밖 글자 넘침 방치**: 상자 안 문구는 15~22자 이내 핵심 어구로 줄이고, `check`의 `viewBox` 잘림 경고가 0건이 될 때까지 폭·높이를 조정한다.
